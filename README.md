# FPV Техшкола

Отдельное Android-приложение для технического обучения FPV, не связанное с приложениями Изи.

## Разделение проектов

- Приложение: `FPV Техшкола`
- Android package ID: `com.artist.fpvschool`
- Каталог репозитория: `fpv-tech-school`
- Workflow сборки: `Build FPV Tech School APK`
- APK artifact: `FPV-Tech-School-APK-<номер запуска>`

## Версия 0.2.0

Первое занятие «Устройство FPV-дрона и связь» основано на 31-слайдовой презентации. Оно разбито на 19 карточек в четырёх частях: типы БПЛА, компоненты FPV-дрона, протоколы управления и видеосвязь. В занятии используются фотографии и схема из исходной презентации, а прогресс сохраняется на устройстве. В конце есть тест из пяти вопросов. Видеоролик пока отмечен как будущий материал.

Остальные темы курса показываются в каталоге и будут добавляться отдельно.

Сборка рассчитана на GitHub Actions: GitHub-hosted runner, Temurin JDK 17, Gradle 9.6.0, Android Gradle Plugin 9.5.0 и Android API 36.
